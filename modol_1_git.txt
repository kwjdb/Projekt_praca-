komenda do sprawdzania wersjiw terminalu:
git --version

komenda do tworzenia repozytorium, tworzy ona katalog git-a:
git init

aby git nie zapisywał jakiegoś pliku w szeczgólności całego środowiska robimy coś takiego, że tworzymy plik
.gitignore
który będzie plikiem konfiguracyjnym i zapisane w nim nazwy pliku w takiem formacie :.venv/  nie będą zaciągane do repo

Poelcenie do przypisania danych autora:

git config --global user.name "Hubert"
git config --global user.email "hub.jatczak@gmail.com"


Polecenie do sprawdzania statusu
git status


Przygotuj pliki do zapisu (Staging): Wpisz w terminalu komendę, która wrzuca wszystkie pliki z
Twojego folderu do "poczekalni" przed zapisem (kropka na końcu oznacza "wszystko"):
git add .


po tym jak dodamy do buforu komenda git commit -m "tresc "  wypycha cały bufor do repo



git status – Pokazuje na czerwono pliki, które zostały zmienione, i na zielono te, które są gotowe do zapisu (to bardzo przydatny nawyk, żeby wiedzieć, co dokładnie za chwilę wyślesz).

git add . – Przenosi wszystkie zmienione pliki do "poczekalni". Kropka na końcu oznacza "dodaj wszystkie zmodyfikowane pliki z tego folderu".

git commit -m "Twój opis zmian" – Tworzy trwały zapis (lokalnego save'a) na Twoim komputerze. Zawsze używaj flagi -m, żeby nie wciągnęło Cię z powrotem do Vima.

git push – Wypycha Twój zapisany kod prosto do chmury na GitHuba.
